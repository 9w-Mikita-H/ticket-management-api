# Функциональность Api:

---

## Неаутентифицированные пользователи

---

### Аутентификация

* Регистрация (минимальная: логин + пароль)
* Логин (JWT)

---

## Общие функции (для всех аутентифицированных пользователей)

---

### Получение списка тикетов

* Пагинация (page, pageSize)
* Сортировка:

    * по CreatedAt
    * по UpdatedAt

* Фильтрация:

    * по статусу (Open / InProgress / Resolved / Closed)

* Поиск:

    * по названию тикета
    * по логину автора
    * нечувствителен к регистру
    * частичное совпадение

Поведение:

* Обычный пользователь видит только свои тикеты. Поиск по логину доступен только с использоваем своего
* Агент видит все тикеты

---

### Получение одного тикета

* Детальная информация
* Автор
* Статус
* Комментарии

---

## User (обычный пользователь)

---

### Может:

### 1. Создать тикет

* Title
* Description
* Статус по умолчанию: Open

---

### 2. Редактировать тикет (ограниченно)

Разрешено, если:

* тикет в статусе Open
* нет комментариев от агента

Можно менять:

* Title
* Description

---

### 3. Написать комментарий к своему тикету

Разрешено, если:

* тикет не Closed

---

### 4. Закрыть тикет

Поведение:

Тикет в первую очередь закрывается пользователем для минимизации преждевременного закрытия. Доступ Агента к этой функции вынужденный и в рамках особых ситуаций

Разрешено, если:

* тикет Open
* тикет Resolved

---

### Не может:

* Удалять тикеты
* Менять статус (кроме закрытия)
* Видеть чужие тикеты
* Комментировать чужие тикеты
* Редактировать после начала обработки

---

## Agent (расширенный пользователь)

---

### Agent = User + дополнительные права

---

### Дополнительно может:

### 1. Видеть все тикеты

---

### 2. Комментировать любой тикет

Разрешено, если:

* тикет не Closed

---

### 3. Менять статус любого тикета

* Open → InProgress
* InProgress → Resolved
* InProgress → Open
* Resolved → Closed
* Resolved → InProgress

---

### Не может:

* Удалять тикеты
* Редактировать чужой текст тикета

---

# Что намеренно отсутствует

* Удаление тикетов
* Редактирование комментариев
* Удаление комментариев
* История изменений
* Уведомления
* Email
* @Упоминания
* Теги / категории
* Администраторская панель

---

## Инварианты системы

1. Пользователь может видеть только свои тикеты.
2. После появления комментария от агента тикет нельзя редактировать.
3. Тикет в статусе Closed нельзя:

    * редактировать
    * комментировать

4. Все операции проходят через авторизацию (JWT).
